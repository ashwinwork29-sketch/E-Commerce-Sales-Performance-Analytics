# E-Commerce Sales & Performance Analytics

## 📌 Project Overview

An end-to-end E-Commerce Sales Analysis project using Python, SQL, and Power BI to analyze sales performance, customers, products, payments, and delivery performance.

## 🛠️ Tools & Technologies

- Python
- Pandas
- MySQL
- SQL
- Power BI
- DAX
- Excel

## 🔄 Project Workflow

Kaggle Dataset
↓
Python/Pandas Data Cleaning
↓
MySQL Data Analysis
↓
DAX Measures
↓
Power BI Dashboard
↓
Business Insights

## 📊 Dashboard Features

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Monthly Revenue Trend
- Revenue by Product Category
- Revenue by Region
- Top 10 Customers
- Payment Method Analysis
- Customer Rating Analysis
- Delivery Performance
- Interactive Filters

## 💡 Key Business Questions

- What is the monthly revenue trend?
- Which product categories generate the highest revenue?
- Which regions perform best?
- Who are the top customers?
- Which payment method is most popular?
- Which categories have better customer ratings?
- Which regions/categories have longer delivery times?
